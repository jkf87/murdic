How it works

  1. Place your cursor

    Choose a text field in Notes, Mail, or another app that accepts paste.

  2. Hold the key and speak

    Hold right Option. A floating microphone meter shows that recording has started.

  3. Release to write

    The locally edited sentence lands at your cursor. Your previous clipboard contents are restored.

Why murdic?

No subscription

Install without an account. There is no word allowance or monthly fee.

Works offline

Once the Whisper model is cached, transcription and rule-based editing run offline.

Private by default

Default settings keep audio and text on your Mac. Temporary recordings are removed after processing.

Editable source

The murdic app and cleanup rules are available under MIT. The separately installed Murmur core has its own terms.

Install on your Mac

Tested on Apple Silicon with macOS 26.5. Set up the developer tools with xcode-select --install and brew install python. These commands install murdic and the Murmur core.

Terminal 
git clone https://github.com/jkf87/murdic.git && cd murdic
/opt/homebrew/bin/python3 -m venv .venv && .venv/bin/pip install 'git+https://github.com/jkf87/murmur.git@master#subdirectory=core'
make run

The first run downloads the model. Once it is cached, default dictation works offline.

FAQ

Which permissions does it need?

Allow Microphone to record and Accessibility to paste. Enable Input Monitoring if macOS requires it for the shortcut. To add a missing entry, click +, press ⌘⇧G, and enter ~/Applications/murdic.app.

Which Macs can run it?

It is built for Apple Silicon. We tested an M5 on macOS 26.5 with Homebrew Python 3.14.6. Intel Macs and other macOS versions have not been verified.

Can I dictate in English?

murdic is Korean-first. English terms can appear in Korean sentences, but the model is set to Korean. A Samantha test with an English-only sentence produced Korean text with a different meaning. There is no dedicated English mode.

What happens if I enable an LLM hook?

The hook is off by default. If you configure an external service, the locally cleaned transcript is sent to that service.
