    로컬에서 정리한 문장이 커서에 들어갑니다. 기존 클립보드 내용도 복원됩니다.

오프라인 받아쓰기

Whisper 모델을 한 번 받은 뒤에는 인터넷 없이 전사와 규칙 정리를 실행합니다.

내 Mac에 머무는 음성

기본 설정은 음성과 텍스트를 외부로 보내지 않습니다. 임시 녹음은 처리 후 삭제합니다.

직접 고치는 정리 규칙

머딕의 앱과 정리 규칙은 MIT로 공개합니다. 별도 설치하는 Murmur 코어에는 업스트림 조건이 적용됩니다.

내 Mac에 설치하기

Apple Silicon과 macOS 26.5에서 검증했습니다. 먼저 xcode-select --install과 brew install python으로 개발 도구를 준비하세요. 아래 명령은 머딕과 Murmur 코어를 설치합니다.

Terminal 
git clone https://github.com/jkf87/murdic.git && cd murdic
/opt/homebrew/bin/python3 -m venv .venv && .venv/bin/pip install 'git+https://github.com/jkf87/murmur.git@master#subdirectory=core'
make run

첫 실행에는 모델 다운로드가 필요합니다. 이후에는 기본 설정으로 오프라인에서 사용할 수 있습니다.

FAQ

사용 중인 마이크를 어떻게 확인하고 바꾸나요?

메뉴바의 ‘마이크: 장치 이름’에서 현재 입력을 확인하고 다른 마이크를 선택하세요. 설정 및 권한 창에서는 ‘3초 테스트’로 입력 레벨을 확인할 수 있습니다. 선택한 장치가 분리되면 시스템 기본값으로 돌아갑니다.

어떤 권한이 필요한가요?

마이크는 녹음, 손쉬운 사용은 붙여넣기에 사용합니다. 단축키에 입력 모니터링이 필요하면 macOS 설정에서 허용하세요. 목록에 없다면 +를 누르고 ⌘⇧G로 ~/Applications/murdic.app을 선택하세요.

어떤 Mac에서 쓸 수 있나요?

Apple Silicon Mac용입니다. M5, macOS 26.5, Homebrew Python 3.14.6에서 검증했습니다. Intel Mac과 다른 macOS 버전은 검증하지 않았습니다.

영어도 받아쓸 수 있나요?

한국어 문장에 영어 용어를 섞어 쓸 수 있습니다. 전사 언어와 정리 규칙은 한국어 기준입니다. 영어만 읽은 Samantha 음성 테스트에서는 의미가 달라진 한국어 문장이 나왔습니다. 현재 영어 전용 모드는 없습니다.

LLM 정리를 켜면 어떻게 되나요?

기본값은 꺼짐입니다. 외부 훅을 직접 설정하면 로컬에서 정리한 텍스트가 선택한 서비스로 전송됩니다.
